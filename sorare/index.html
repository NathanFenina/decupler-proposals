Méthodologie

D'où viennent ces chiffres

Cette cartographie combine deux couches de données réelles, aucune ne provient d'une estimation ou d'une extrapolation :

  • SEO — Ubersuggest : autorité de domaine, trafic organique, backlinks, mots-clés indexés.
  • GEO — 5 prompts de découverte neutres (jamais la marque nommée) × 3 moteurs IA (ChatGPT, Claude, Gemini), appels API réels et horodatés.
  • Performance — Google PageSpeed Insights, score réel sur la page d'accueil.

Opportunités

Par où commencer

🔎

Combler le vide sémantique

Seulement 156377 mots-clés indexés — prioriser 10-15 pages sur les requêtes de découverte de la catégorie, avant même de penser citation IA.

🤖

Contenu extractible

Structurer les pages où la légitimité produit est la plus forte, dans un format que les IA peuvent citer directement (définitions, comparatifs, données chiffrées).

⚡

Vitesse du site

Score PageSpeed sous 50 : ça freine la conversion même quand le trafic ou la citation IA finit par arriver.
